yu_ai · Java → AI Agent 学习项目

基于 Spring AI + DeepSeek 的 8 个递进学习模块。点击下面的链接即可触发对应接口。

模块 1 · 基础对话 入门

ChatClient 同步 / 流式调用，类比 RestTemplate。
/m1/chat /m1/stream 聊天界面 ↗ 原始 SSE（看协议）

模块 2 · Prompt 工程

System Role + 占位符模板 + 外部 .st 文件，让 prompt 可独立维护。
/m2/translate /m2/review (POST)

模块 3 · 多轮记忆

ChatMemory + Advisor 自动维护对话历史，按 conversationId 隔离。
第 1 轮：自我介绍 第 2 轮：考记忆

模块 4 · 结构化输出

LLM 输出直接映射成 Java POJO，与现有业务代码打通。
/m4/movie (单对象) /m4/movies (列表)

模块 5 · 工具调用 (Function Calling)

LLM 自主调用你的 Java 方法 —— 天气、计算器、时间。
/m5/ask 查天气 /m5/ask 多工具协同

模块 6 · RAG 检索增强 需要先 POST /m6/load

本地 embedding + 向量库 + QuestionAnswerAdvisor 自动检索拼 prompt。
点击灌入示例文档 /m6/ask 问 HR /m6/ask 问技术

模块 7 · ReAct Agent

让模型按 Thought-Action-Observation 循环自主选择工具。
/m7/run 多步任务

模块 8 · Workflow 编排

Chain / Parallel / Routing 三种典型工作流模式。
/m8/chain 串行写作 /m8/route 路由

完整项目说明见 README.md。建议按 1 → 8 顺序学习，每模块大约 1-2 小时。
