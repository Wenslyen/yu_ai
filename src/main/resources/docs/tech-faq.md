# 技术 FAQ（示例）

## Q1: 如何申请数据库账号？
答：在工单系统选择「DBA - 数据库账号申请」，填写库名、读写权限、用途，DBA 审批后 1 个工作日内开通。生产库账号必须双人审批。

## Q2: 如何上线一个新服务？
答：
1. 提交 RFC 文档到 wiki，至少 2 名技术 leader review。
2. 通过后在 CI/CD 平台创建 pipeline，绑定 git 仓库。
3. 联系 SRE 申请域名、SLB、监控告警。
4. 灰度发布：5% → 50% → 100%，每阶段观察 30 分钟。

## Q3: 线上 P0 故障怎么处理？
答：
1. 立刻拉应急群（@oncall + @团队 leader）。
2. 5 分钟内启动止损（回滚优先于定位原因）。
3. 1 小时内恢复服务。
4. 24 小时内输出复盘文档。

## Q4: 接口性能慢怎么排查？
答：先看 APM 调用链 → 定位慢的节点（DB / 下游服务 / GC） → DB 慢看慢查询日志 + EXPLAIN → 服务慢看 GC 日志 + 火焰图 → 网络慢看抓包。
