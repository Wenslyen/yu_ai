yu_ai · Java → AI Agent 学习项目

基于 Spring AI Alibaba + 通义千问 (DashScope) 的 9 个递进学习模块。点击下面的链接即可触发对应接口。

当前分支 feature/spring-alibaba-ai · 启动前请设置环境变量 DASHSCOPE_API_KEY · 前往 DashScope 申请 key ↗

通用 · Spring AI 模块 1 ~ 8

业务代码与具体框架解耦，main 分支与本分支共享

模块 1 · 基础对话 入门

ChatClient 同步 / 流式调用，类比 RestTemplate。
/m1/chat /m1/stream 聊天界面 ↗ 原始 SSE（看协议）

模块 2 · Prompt 工程

System Role + 占位符模板 + 外部 .st 文件，让 prompt 可独立维护。
/m2/translate /m2/review (POST)

模块 3 · 多轮记忆

ChatMemory + Advisor 自动维护对话历史，按 conversationId 隔离。
第 1 轮：自我介绍 第 2 轮：考记忆

模块 4 · 结构化输出

LLM 输出直接映射成 Java POJO，与现有业务代码打通。
/m4/movie (单对象) /m4/movies (列表)

模块 5 · 工具调用 (Function Calling)

LLM 自主调用你的 Java 方法 —— 天气、计算器、时间。
/m5/ask 查天气 /m5/ask 多工具协同

模块 6 · RAG 检索增强 需要先 POST /m6/load

DashScope embedding + 向量库 + QuestionAnswerAdvisor 自动检索拼 prompt。
点击灌入示例文档 /m6/ask 问 HR /m6/ask 问技术

模块 7 · ReAct Agent

让模型按 Thought-Action-Observation 循环自主选择工具。
/m7/run 多步任务

模块 8 · Workflow 编排

Chain / Parallel / Routing 三种典型工作流模式。
/m8/chain 串行写作 /m8/route 路由

阿里专属 · DashScope / Alibaba 生态 模块 9

本分支独有；切回 main 这部分会编译失败（依赖 spring-ai-alibaba）

模块 9.1 · 多模态看图（Qwen-VL）

Qwen-VL-Plus 模型支持图像 + 文本输入，适合做 OCR、商品识别、图表解读。
/m9/vision 看官方示例图

模块 9.2 · 联网搜索（DashScope EnableSearch）

服务端开关，让模型自动联网获取实时信息，适合时效性问题。
/m9/search 时效问题 /m9/search 实时数据

模块 9.3 · Nacos Prompt 热更新 演示用，需自行接 Nacos

Prompt 存 Nacos 配置中心，改完不重启就生效。当前为兜底实现，开启 Nacos 步骤见类注释。
/m9/prompt 客服问答

完整项目说明见 README.md。建议按 1 → 9 顺序学习，每模块大约 1-2 小时。
